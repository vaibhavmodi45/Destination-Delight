# 🌏 Destination Delight – Travel Discovery Platform
<p >
  <h3>Destination Delight -  Your Travel Companion <a href= "https://destinationdelight.netlify.app/">explore it by clicking here👈</a></h3>
</p>


Welcome to **Destination Delight**, a visually stunning, multi-page travel discovery platform designed to help you explore and plan unforgettable journeys across India. With curated content, dynamic APIs, and smart travel tools, Destination Delight is your one-stop solution for seamless, informative, and engaging travel planning.

---

## 🚀 Features

- **Curated Destinations:**  
  Discover handpicked Indian destinations with rich descriptions, images, and Google Maps integration.

- **Smart Search & Filters:**  
  Find destinations by name or filter by categories like Hill Stations, Beaches, Heritage Sites, Adventure, and Pilgrimage.

- **Dynamic Blogs:**  
  Enjoy both featured and real-time travel blogs, with the latest fetched from Wikipedia’s RESTful API.

- **Travel Helper Tools:**  
  - **Currency Converter:** Real-time exchange rates for global currencies.
  - **Weather Forecast:** 7-day weather outlook for any city.
  - **Language Translator:** Instantly translate text between major world languages.
  - **AI Trip Planner:** *(Coming Soon)* Generate personalized itineraries powered by AI.
  - **Packing Assistant & Nearby Attractions Finder:** *(Coming Soon)*

- **Interactive UI:**  
  Smooth scroll-based animations with ScrollReveal.js and a fully responsive Bootstrap layout.

- **Contact & Feedback:**  
  Reach out via a modern, embedded contact form.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **APIs:**  
  - [Wikipedia RESTful API](https://en.wikipedia.org/api/rest_v1/) (Dynamic blogs)
  - [Google Maps API](https://developers.google.com/maps/documentation) (Maps integration)
  - [Open-Meteo API](https://open-meteo.com/) (Weather)
  - [LibreTranslate API](https://libretranslate.com/) (Translation)
  - [ExchangeRate API](https://www.exchangerate-api.com/) (Currency)
- **Libraries:**  
  - [ScrollReveal.js](https://scrollrevealjs.org/) (Animations)
- **Tools:** Visual Studio Code, GitHub

## ✨ How It Works

- **Explore Destinations:**  
  Use the search bar or category filter to find destinations. Each result includes a summary, image, and a link for more info.

- **Read Blogs:**  
  Browse featured stories or check out the latest travel blogs fetched live from Wikipedia.

- **Use Travel Tools:**  
  Access currency conversion, weather forecasts, and language translation directly from the Travel Helper page.

- **Plan with AI:**  
  *(Coming Soon)* Enter your city, trip duration, and interests to get a personalized itinerary.
